# Afra Nazeer — Portfolio

A local-first portfolio built with Next.js, TypeScript, and Tailwind CSS.

## Run locally

```bash
npm install
npm run dev
```

Open `http://localhost:3000`.

## Production check

```bash
npm run build
npm run start
```

The metadata uses `http://localhost:3000` by default. Set `NEXT_PUBLIC_SITE_URL` and `NEXT_PUBLIC_BASE_PATH` when publishing beneath a repository path. GitHub Pages deployment is automated by `.github/workflows/deploy.yml`.
